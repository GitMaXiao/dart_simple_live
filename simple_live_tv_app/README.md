# Simple Live TV App

专为 Android TV 与大屏设备设计的 Simple Live 客户端，针对遥控器焦点交互进行了深度优化。

## 📺 特性

- **大屏遥控交互**：全面适配 D-Pad 方向键与遥控器控制，操作便捷。
- **多平台聚合**：支持 Bilibili、斗鱼、虎牙、抖音各大平台直播浏览。
- **全屏沉浸播放**：支持清晰度无缝切换、实时弹幕展示与控制。
- **多设备同步**：支持扫码/局域网与手机端同步关注列表。

## 🚀 编译与安装

```bash
# 获取依赖
flutter pub get

# 构建 Android TV APK
flutter build apk --release
```
